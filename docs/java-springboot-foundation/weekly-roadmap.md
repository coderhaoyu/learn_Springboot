# 每周学习路线

## 基础补课阶段：进入第 1 周前

### 阅读章节

- 第 1 章：变量、类型、对象；
- 第 2 章：方法，重点阅读；
- 第 3 章：类、接口、泛型；
- 第 4 章：集合和常用方法；
- 第 5 章：异常和注解；
- 第 6 章：Maven 和项目结构。

### 练习目标

1. 能读懂 `User` 类的字段、构造方法和 Getter / Setter；
2. 能解释 `UserService.findById` 的参数、返回值和调用链；
3. 能区分 `CreateUserRequest`、`User` 和 `UserVo`；
4. 能说出 `List<User>` 中泛型的作用；
5. 能解释 `throw new BusinessException(...)` 会发生什么。

### 基础验收

请用自己的话回答：

```text
一个 Java 方法由哪些部分组成？
UserService 为什么需要 UserMapper？
一个对象从哪里创建？
为什么 Controller 不直接调用 Mapper？
```

## 第 1 周：真正的数据库 CRUD

对应详细计划：[第 1 周：完成真正的数据库 CRUD](../weekly/week-01-database-crud.md)

### 需要阅读

- 第 1 章：类型和对象；
- 第 2 章：方法和调用链；
- 第 6 章：项目结构；
- 第 9 章：HTTP 方法和参数；
- 第 11 章：SQL 基础；
- 第 12 章：Mapper 和 XML；
- 第 13 章：CRUD 和分页。

### 本周目标

把内存数据访问替换为 MySQL，打通：

```text
HTTP → Controller → Service → Mapper → XML SQL → MySQL → JSON
```

### 本周要理解的概念

- `POST`、`GET`、`PUT`、`DELETE`；
- `CREATE TABLE`、`INSERT`、`SELECT`、`UPDATE`、`DELETE`；
- 主键、自增、唯一约束；
- Mapper 接口和 XML 的匹配；
- `#{}` 参数绑定；
- Entity 如何承载数据库行；
- 分页的 `LIMIT`、`OFFSET` 和 `COUNT(*)`。

### 本周完成后应能回答

1. `UserController` 如何把请求交给 `UserService`？
2. `UserMapper.findById` 如何找到 XML 中的 SQL？
3. `#{id}` 的值从哪里来？
4. SQL 查询结果如何变成 `User`？
5. 为什么重启应用后数据还存在？
6. 为什么邮箱需要数据库唯一约束？

## 第 2 周：把 CRUD 做成规范接口

对应详细计划：[第 2 周：把 CRUD 做成规范接口](../weekly/week-02-standard-crud.md)

### 需要阅读

- 第 2 章：方法；
- 第 4 章：集合和分页结果；
- 第 8 章：配置和注解；
- 第 9 章：MVC 参数绑定；
- 第 10 章：校验、DTO、VO 和异常；
- 第 13 章：分页和数据约束；
- 第 14 章：定向测试。

### 本周目标

让接口具备清晰的输入、输出和错误语义：

```text
格式错误 → 400
资源不存在 → 404
业务冲突 → 409
未知系统错误 → 500
```

### 本周要理解的概念

- DTO 是输入边界；
- VO 是输出边界；
- `@Valid` 和 `@Validated`；
- `@NotBlank`、`@Email`、`@Min`、`@Max`；
- `@RestControllerAdvice` 和 `@ExceptionHandler`；
- 分页响应结构；
- Service 查重与数据库唯一约束的区别。

### 本周完成后应能回答

1. 邮箱格式错误为什么不是 409？
2. 邮箱重复为什么不是 400？
3. 为什么 Entity 不直接作为所有接口响应？
4. 为什么 Controller 不负责业务查重？
5. 为什么分页需要列表查询和总数查询？
