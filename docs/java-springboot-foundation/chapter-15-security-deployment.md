### 15.1 认证和授权

- 认证：你是谁？
- 授权：你能做什么？

例如：

```text
登录成功 → 认证通过
未绑定用户不能查看共同记录 → 授权失败
```

### 15.2 密码摘要

密码不应该明文保存。注册时保存 BCrypt 摘要，登录时比较输入密码和摘要是否匹配。

### 15.3 JWT 请求链路

```text
登录接口校验账号密码
    ↓
签发 JWT
    ↓
客户端携带 Authorization: Bearer <token>
    ↓
安全过滤器解析 Token
    ↓
写入安全上下文
    ↓
Controller / Service 取得当前用户
```

### 15.4 401 和 403

- 401：没有通过身份认证；
- 403：已经知道是谁，但没有权限。
